# Обновление матчей и турниров

- После подтверждения результата организатором победитель автоматически переносится в соответствующий слот следующего раунда Single Elimination.
- Если завершён финальный матч, статус турнира меняется на `completed`.
- Убраны отдельные пункты боковой навигации «Турнирная сетка» и «Мои матчи»: основной вход — «Турниры» → «Подробнее».
- В подробностях активного турнира участник видит свои матчи именно этого турнира; список не смешивает матчи из разных событий.

Ограничения текущей реализации: автоматическое продвижение реализовано для сетки Single Elimination. Для полноценного Double Elimination (нижняя сетка), Swiss pairing и серверно-атомарного подтверждения результатов нужна отдельная схема матчей/транзакция на стороне Supabase. Перед публикацией необходимо проверить приложение на двух аккаунтах и применить имеющиеся SQL-миграции турниров.
