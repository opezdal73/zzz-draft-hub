# Локальные изображения

Иконки встроены из предоставленного архива в формате WebP. Агентские иконки лежат в `public/images/agents/<id>.webp`, амплификаторы — в `public/images/amplifiers/catalog-NNN.webp`. В `IMAGE-ASSET-REPORT.json` перечислены сопоставления и записи, для которых не нашлось точного файла. Папка с костюмами не использовалась.

Важно: для ряда амплификаторов источник использует английские имена, поэтому после визуальной проверки сопоставление некоторых редких/новых названий может потребовать поправки.
