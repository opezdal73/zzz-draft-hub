# Изменения: ники в драфте и аватары профиля

- В драфте загружаются никнеймы обоих участников из `public.profiles`, поэтому обе стороны видят оба ника.
- В профиле выбор аватара сохраняется в `profiles.avatar_id` для авторизованного пользователя; локальный демо-режим сохраняет выбор в состояние приложения.
- Сохранение никнейма обновляет `profiles.nickname` и Supabase Auth metadata.
- Все 195 WebP-иконок из предоставленного архива доступны в выборе аватара (агенты, образы и амплификаторы). Файлы находятся в `public/images/profile-avatars/`.
- Сохранены совместимые отображения старых ID аватаров (anby, nicole и др.), чтобы существующие профили не потеряли изображения.

Для показа ников второго участника политика чтения `public.profiles` должна разрешать чтение профилей авторизованным пользователям. В текущих SQL-файлах проекта такая политика есть в `supabase/online_rooms.sql`.
